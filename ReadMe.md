### Projetos em destaque

**[rag-from-scratch](https://github.com/Joaovitor12j/rag-from-scratch)**
Worker assíncrono em Python que implementa um pipeline de RAG do zero — sem LangChain, sem LlamaIndex — para revisão técnica de laudos de engenharia civil contra normas ABNT. Chunking, embeddings e busca vetorial implementados diretamente (tiktoken + pgvector). Clean Architecture com `Protocol`s como ports, anonimização de PII antes de qualquer chamada ao LLM, tipagem ponta a ponta com Pydantic v2 e `mypy --strict`.
`Python` `arq/Redis` `PostgreSQL + pgvector` `spaCy` `OpenAI API`

**[olist-elt-pipeline](https://github.com/Joaovitor12j/olist-elt-pipeline)**
Pipeline ELT completo sobre o dataset Olist E-Commerce: ingestão em Postgres, transformação com dbt, orquestração via Airflow e deploy em BigQuery. Ambiente 100% containerizado, sem dependência de Python no host.
`dbt` `Airflow` `PostgreSQL` `BigQuery` `Docker`
