### Projetos

**[rag-from-scratch](https://github.com/Joaovitor12j/rag-from-scratch)** — pipeline de RAG do zero (sem LangChain/LlamaIndex) para revisão de laudos de engenharia contra normas ABNT. Chunking, embeddings e busca vetorial com tiktoken + pgvector; Clean Architecture, anonimização de PII e `mypy --strict`.
`Python` `arq/Redis` `pgvector` `spaCy` `OpenAI API`

**[olist-elt-pipeline](https://github.com/Joaovitor12j/olist-elt-pipeline)** — ELT sobre o dataset Olist: ingestão em Postgres, dbt, orquestração com Airflow e deploy em BigQuery, tudo containerizado.
`dbt` `Airflow` `PostgreSQL` `BigQuery` `Docker`
